Créer le jeton
  1. Ouvrir la création d'un jeton GitHub ↗ (jeton fine-grained).
  2. Expiration : 1 an.
  3. Repository access : Only select repositories → moreauremi.github.io.
  4. Repository permissions : Contents et Actions en Read and write, rien d'autre.
  5. Generate token, puis le coller ici.

Le jeton reste dans ce navigateur et n'est envoyé qu'à GitHub. « Se déconnecter » l'efface.
